# History

DbUp began life as the database migration tool inside
[FunnelWeb](https://github.com/funnelweblog/FunnelWeb), an open source ASP.NET MVC blog engine.

Despite its humble origins, DbUp always thought it could aspire to something bigger. It went out
into the world on its own, making its own way in life: the little script runner that could.

## DbBump

DbBump is a fork of [DbUp](https://github.com/DbUp/DbUp). Over the years DbUp collected a large
number of open issues and pull requests. The goal of DbBump is to work through them: review them,
triage them, fix them and merge them.

DbBump keeps DbUp's API and namespaces, so moving to it needs only a package change. Issues for the
fork are tracked at [DbBump/DbBump](https://github.com/DbBump/DbBump/issues).
